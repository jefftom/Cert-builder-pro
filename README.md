# CertBuilder Pro

A modern visual certificate builder for WordPress. Replaces LearnDash's
certificate system with a drag-and-drop builder (React + Fabric.js), a TCPDF
rendering engine, and QR-code verification.

## Requirements

- WordPress 5.8+
- PHP 7.4+ (developed against PHP 8.4)
- For development: Composer, Node.js 18+ / npm

## Project layout

| Path | Purpose | Tracked in git? |
| --- | --- | --- |
| `certbuilder-pro.php` | Plugin bootstrap | yes |
| `includes/` | PHP (connectors, PDF engine, REST API, …) | yes |
| `admin/`, `public/` | Admin views and public verification page | yes |
| `assets/templates/` | Pre-built certificate templates (JSON) | yes |
| `builder/src/` | React builder source | yes |
| `builder/dist/` | Compiled builder bundle | no — built |
| `vendor/` | Composer dependencies (TCPDF, QR code) | no — installed |
| `assets/fonts/` | Bundled TTF fonts (~8.6MB) | no — fetched |

The three "no" rows are generated artifacts, kept out of git the same way and
regenerated by the steps below.

## Development setup

```bash
# 1. PHP dependencies (TCPDF, QR code, dev tooling)
composer install

# 2. Compile the visual builder
cd builder && npm install && npm run build   # or `npm start` to watch

# 3. Fetch the certificate fonts into assets/fonts/
bin/download-fonts.sh
```

After these three steps the plugin runs from a working copy. The builder bundle
is emitted to `builder/dist/index.{js,css}` (plus `index.asset.php`), which is
exactly what `includes/Admin/Admin.php` enqueues.

## Building an installable release

```bash
bin/build-release.sh
```

This runs the three setup steps (with `composer install --no-dev`) and packages
only the runtime files into `dist/certbuilder-pro-<version>.zip`, ready to
upload via **Plugins → Add New → Upload Plugin**.

## Fonts

See [`assets/fonts/README.md`](assets/fonts/README.md) for the font list,
licensing (SIL OFL 1.1 / Apache 2.0), and how they are fetched. If a font file
is absent at runtime the PDF generator falls back to Helvetica for that element.
